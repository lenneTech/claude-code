All three come from the same marketplace and are installed with `lt claude plugins` (or
`lt claude plugins <name>`). `lt-offers` and `lt-showroom` work with an account on their platform and sign in
through OAuth in the browser on first use. Everything company-specific comes from that account, not from the plugin.

## lt-offers

Business offers on [angebote.lenne.tech](https://angebote.lenne.tech) and concept folders (Konzeptmappen) on
konzept.lenne.tech, through the MCP servers `offers-api` (production) and `offers-api-demo` (the demo instance). A
prompt that mentions "demo" goes to the demo instance, everything else to production.

| Command | What it does |
|---|---|
| `/lt-offers:offers:create [customer]` | Creates an offer: gathers the requirements, builds the blocks, publishes |
| `/lt-offers:offers:concept [customer-or-topic]` | Creates a concept folder from workshop material: linked offer, sources, outline, blocks, sharing text |
| `/lt-offers:offers:optimize [offer-or-concept-id]` | Analyzes and improves an existing offer or concept folder |

Offers are written from the account's knowledge base: company, services, team, references and template offers. When
something is missing, the workflow asks and offers to store the answer for the next offer.

Details: [plugins/lt-offers/README.md](https://github.com/lenneTech/claude-code/blob/main/plugins/lt-offers/README.md)

## lt-showroom

Project analysis and showcases on [showroom.lenne.tech](https://showroom.lenne.tech) through the MCP server
`showroom-api`. The analysis and the screenshots come from a throwaway clone under `~/.lt-showroom/`, so nothing is
written into your checkout or the project repository. New showcases are drafts (internal, anonymous) with
placeholders instead of customer names.

| Command | What it does |
|---|---|
| `/lt-showroom:showroom:analyze` | Analyzes a project for a showcase: features, pages, startup, tech stack, project facts |
| `/lt-showroom:showroom:screenshot` | Captures feature screenshots (desktop and mobile) with demo data |
| `/lt-showroom:showroom:create` | Creates the showcase as a draft, or updates the one the repository already has |
| `/lt-showroom:showroom:update` | Updates a showcase after code changes, re-analyzing only what changed |

Screenshots need the `chrome-devtools` MCP server of `lt-dev`, so install both.

Details: [plugins/lt-showroom/README.md](https://github.com/lenneTech/claude-code/blob/main/plugins/lt-showroom/README.md)

## lt-tools

General-purpose tools that do not belong to the stack.

| Command | What it does |
|---|---|
| `/lt-tools:save-website <url> [--zip]` | Saves a website with all pages and assets as an offline copy that opens from `file://`, checks it against the live site in headless Chrome, and optionally zips it |

It needs Node.js 22 or newer and Google Chrome or Chromium for the comparison.

Details: [plugins/lt-tools/README.md](https://github.com/lenneTech/claude-code/blob/main/plugins/lt-tools/README.md)
