## Recommended permission mode: auto

Work in **auto mode** (`Shift+Tab`, or `permissions.defaultMode: "auto"` in your settings). A classifier approves
routine actions and asks only for risky ones. That is the balance these plugins are built for: protected by default,
nobody slowed down, a prompt only for a rare or sensitive action.

Manual (`default`) mode is not practical for agentic work with these plugins, whatever the allow list says. Measured
over 151 real `lt-dev` sessions, it would ask about 131 times per session (median). Only about a third of those
prompts could be removed by any allow rule at all, because Claude Code asks for shell constructs such as variables,
`$(…)` or paths outside the project regardless of rules.

## Allow rules

The allow rules still matter in auto mode. A rule resolves an action before the classifier sees it, so every rule is
kept narrow (otherwise it would skip the safety check), and the frequent harmless ones save the classifier round trip.

[`plugins/lt-dev/permissions.json`](https://github.com/lenneTech/claude-code/blob/main/plugins/lt-dev/permissions.json)
lists the narrow Bash commands the skills and agents run without a prompt. `lt claude plugins` copies it into
`~/.claude/settings.json`, where every rule applies in every project.

- **Removed rules are cleaned up.** A rule the plugin narrowed or dropped is listed in the file's `formerPatterns`
  array, and the CLI removes it once from your settings. A rule you add again by hand afterwards stays.
- **Broad tools are not listed.** `curl`, `node`, `docker run`/`exec`, `git push`, `rm`, `cp` and `mv` would approve
  far more than the one call a command needs. The commands that need them grant them for their own turn through
  `allowed-tools`.
- **Plugin helper scripts are not listed either.** Settings do not expand `${CLAUDE_PLUGIN_ROOT}`, and a `*` in a
  script path also matches `../`, so a rule such as `Bash(bash <plugin dir>/*/scripts/*)` would approve any code. The
  commands that run these scripts grant each one by exact name for their own turn. Do not add a wildcard rule for
  them by hand.
