# ADR-006: Claude Code documentation is read from a local cache under `.claude/docs-cache/`, generated from `sources.json`; the cache is the single source of truth for best practices in this repository

**Date:** 2026-01-09 · **Status:** accepted · **Topic:** Documentation
**Origin:** reconstructed 2026-11-18 from git history, CLAUDE.md, .claude/docs-cache/sources.json

## Context

Until 2026-01-09 the repository `CLAUDE.md` told every session to "fetch and apply current best practices" from the
code.claude.com pages with WebFetch. Commit eab54d0 (2026-01-09, 17:17) recorded that those pages "are React apps
with heavy JavaScript - use for manual reference only" and introduced a hand-extracted file
(`best-practices-cache.md`). Version 2.4.2 (a134188, 18:46 the same day) replaced it with `.claude/docs-cache/`,
generated by `.claude/scripts/update-docs-cache.ts` from `sources.json`; 62e9507 (20:29) deleted the hand-extracted
file and added the integrity and version checks. On 2026-09-25 (354845d) the cache switched to the `.md` form of each
page.

## Decision

- Claude Code's documentation, Anthropic's prompting and platform pages, the GitHub READMEs of the plugin, skill and
  official-plugin repositories, and the Claude Code changelog are cached as Markdown in `.claude/docs-cache/`.
- `.claude/docs-cache/sources.json` is the single list of sources. `bun .claude/scripts/update-docs-cache.ts`
  regenerates the files from it and prefers the `md` source type for Anthropic pages; `html` and `spa` remain for
  sites without a `.md` form.
- Work on this repository's elements reads the cache first; `/optimize` checks whether it is outdated and offers to
  refresh it. WebSearch is the fallback.
- A failed fetch keeps the existing file. A page that shrinks sharply is accepted only with `--accept-shrink`, after
  checking whether its content moved to a page of its own.

## Rationale

- eab54d0, `CLAUDE.md`: the code.claude.com pages "are React apps with heavy JavaScript - use for manual reference
  only", listed under "Reference URLs (for manual lookup, NOT for WebFetch)".
- `CLAUDE.md`, source types: the `.md` form is preferred because "the rendered pages lose every heading, the `.md`
  form keeps them and carries more content".
- `CLAUDE.md`, error handling: "If a source fails to fetch, existing cache is preserved (no data loss)".

## Rejected alternatives

- **WebFetch of the live documentation pages** (`CLAUDE.md` before eab54d0): the pages did not render for WebFetch.
- **A hand-extracted best-practices file** (`.claude/skills/marketplace-optimizer/best-practices-cache.md`, eab54d0):
  marked "Legacy cache (deprecated)" in a134188 and deleted in 62e9507.
- **Rendered HTML or SPA pages converted to Markdown** for Anthropic docs: replaced by the `md` source type (354845d),
  because the rendered pages lose their headings.

## Consequences

- The cache serves this repository only; plugin elements cannot read it (ADR-007).
- The cache ages. `check-cache-version.ts` reports when it is outdated, `check-docs-coverage.ts` lists pages it lacks.
- `scripts/scan-secrets.sh` skips `.claude/docs-cache/*`, because the cached pages carry example values.
- House rules 1 and 2 rest on it: tool names come from the cached `tools-reference.md`, and high-impact findings are
  verified against the cached page.
